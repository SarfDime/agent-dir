# Code of Conduct

## Our standard

Contributors and maintainers are expected to be respectful, constructive, and professional. Focus criticism on code, behavior, and technical decisions rather than people.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, deliberate disruption, and sharing private information without permission.

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this code of conduct and may restrict participation when necessary to keep the project constructive and safe.

For security vulnerabilities, use the private reporting process described in [SECURITY.md](SECURITY.md) rather than a public issue.
